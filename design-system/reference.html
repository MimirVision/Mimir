Mimir design system

Every token in tokens.css, rendered. This page is built only from those tokens — if something here looks wrong, the token is wrong, because there is nowhere else for the mistake to hide.

Severity — vocabulary, not palette

A user learns these in the first thirty seconds. Never use one decoratively: a red border meaning “important detail” teaches them that red is sometimes just red, and the red that matters then carries less weight.
