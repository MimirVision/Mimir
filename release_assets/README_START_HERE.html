Install and Scan

  1. 1Run MimirSetup.exe. Install the free beta on your Windows PC.
  2. 2Open Mimir. The app opens to the footage import screen.
  3. 3Choose a footage folder. Select a USB folder or a local folder containing vehicle footage.
  4. 4Scan locally. Pick Fast, Balanced, or Thorough and let Mimir analyze on this device.
  5. 5Review incidents. Open cards, watch the video, review the timeline, and adjust status if needed.

Safety Notes

  • Scan does not move or delete original clips. File movement is manual after review.
  • Delete means Move to Mimir Trash. It is not permanent deletion.
  • You control status per incident. Change Ignore, Review, or Important after watching.
  • Processing stays local in this beta. No footage upload is required for the normal beta flow.
